# Crazsix Stock

เว็บจัดการสต็อก เสื้อผ้า ยอดขาย และรายรับ-รายจ่ายของร้าน Crazsix Store

ข้อมูลถูกเก็บใน Firebase Firestore โดยแยกโค้ดการเชื่อมต่อฐานข้อมูลไว้ที่ `js/firebase-service.js` และตั้งค่าโปรเจกต์ Firebase ได้ที่ `js/firebase-config.js`

ดูขั้นตอนการเชื่อมต่อ Firebase และการเปิดโปรเจกต์ใน VS Code ได้ที่ [FIREBASE_SETUP.md](FIREBASE_SETUP.md)
